# 💜 Nubank Clone

Um projeto mobile desenvolvido com **React Native** e **Expo**, recriando a interface e experiência do aplicativo do **Nubank** como forma de estudo e aprimoramento de habilidades em desenvolvimento front-end mobile.

> ⚠️ **Aviso:** Este é um projeto pessoal, criado exclusivamente para fins de estudo e portfólio. Não possui qualquer vínculo oficial com o Nubank e não deve ser usado para fins comerciais.

---

## 📱 Sobre o projeto

Este projeto tem como objetivo replicar as principais telas e a experiência visual do aplicativo do Nubank, aplicando conceitos de:

- Componentização e reutilização de código
- Navegação entre telas (file-based routing)
- Fidelidade visual (UI/UX) com o app original
- Boas práticas de desenvolvimento em React Native

---

## 🚀 Tecnologias utilizadas

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [Expo Router](https://docs.expo.dev/router/introduction/) (roteamento baseado em arquivos)
- JavaScript / TypeScript

---

## 🧰 Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado
- [Expo Go](https://expo.dev/go) instalado no celular (opcional, para testar via QR Code)

### Passo a passo

1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/nubank-clone.git
cd nubank-clone
```

2. Instale as dependências

```bash
npm install
```

3. Inicie o projeto

```bash
npx expo start
```

4. No terminal, escolha como deseja abrir o app:

- [Development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Emulador Android](https://docs.expo.dev/workflow/android-studio-emulator/)
- [Simulador iOS](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go) — sandbox para testes rápidos

---

## 📂 Estrutura do projeto

O desenvolvimento é feito dentro do diretório `app`, utilizando o sistema de [roteamento baseado em arquivos](https://docs.expo.dev/router/introduction) do Expo Router.

Caso queira reiniciar o projeto com uma base limpa, execute:

```bash
npm run reset-project
```

Esse comando move o código inicial para o diretório `app-example` e cria um novo diretório `app` em branco, pronto para desenvolvimento.
